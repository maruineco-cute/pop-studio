# POP STUDIO — 手描き風POPメーカー

黄色い背景に、太い文字・フチ・下線・ロゴを自由に配置してWeb向けPNGを書き出す、ブラウザ用のPOPメーカーです。

## 起動方法

`index.html` と `assets/` を同じフォルダーに置き、HTTPサーバー経由で開いてください（ローカルファイル直開きではフォントを読み込めないブラウザーがあります）。

```bash
python3 -m http.server 4173
```

ブラウザーで `http://localhost:4173/` を開きます。

## 同梱フォント

同じ作者・たぬき侍さんの以下のフォントを同梱しています。

- `たぬき油性マジック` — `assets/TanukiMagic.ttf`
- `たぬゴ角・標準／太`、`たぬゴ丸・標準／太` — `assets/Tanugo-*.otf`

配布元と各フォントの利用条件：

- https://tanukifont.com/tanuki-permanent-marker/
- https://tanukifont.com/tanugo/
- フォント配布元のreadmeも `assets/` 内に同梱しています。

## 操作

- 背景はPOPイエロー固定。用紙はA4縦・正方形・横長から選べます。
- 文字・下線・ロゴ画像を追加し、ドラッグして配置します。レイヤー一覧は上ほど前面です（↑で前面、↓で背面）。テキスト系の編集欄を上に、用紙・枠線の設定を下にまとめています。
- テキスト設定から自動折り返しをON/OFFできます。OFFなら手動改行だけで表示し、用紙外にはみ出した文字は保存時に用紙端で切り取られます。
- プレビュー上部で文字サイズと字間を調整できます。字間はマイナスにすると、文字が重なるところまで詰められます。重なる場合は先に入力した文字を上に描画します。
- 文字・下線・画像ごとに透明度を調整できます。
- 下線は控えめに揺らし、端は丸めないマジック風。太さ・色・透明度も変更できます。
- タッチ端末では1本指で移動、2本指ピンチで文字サイズと位置を調整できます。
- PNGはWeb向けの1倍サイズで作成し、プレビュー後に保存します。保存操作が使えない埋め込み環境では、画像を長押し（PCは右クリック）して保存してください。
- アップロード画像はブラウザー内で読み込みます。
